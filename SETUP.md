# Setup

## Requirements
- Node.js and npm
- Expo Go for testing on a phone, or a web browser

## Install and Start
From this project folder:

```bash
npm install
npx expo start
```

Press `w` in the Expo terminal for the web version, or scan the QR code with Expo Go.

The movie data and poster designs are included in the app. Browsing, searching, filtering, and saving to the temporary watchlist work offline. The watchlist resets when the app restarts.
